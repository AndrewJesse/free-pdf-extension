# Chrome Web Store listing

Copy these fields into the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole). The name and short description are also written into `manifest.json` by `npm run build:extension`.

## Description

Free PDF merges and compresses PDFs on your device. Documents never leave this browser.

https://free-utils.com

Merge two or more PDFs in the order you choose, then download one combined file. Compress a PDF by redrawing embedded images at a lower resolution on this device. A PDF with no embedded images is left unchanged.

Privacy:

- Processing is 100% local. Files are read in the extension popup and handled there.
- Nothing is uploaded. There is no account and no document server.
- The extension requests no host permissions and no other API permissions.
- There is no remote code, no analytics, and no data collection.

Free PDF is part of Free Utils: https://free-utils.com

## Privacy policy

Free PDF does not collect, transmit, or store user data.

PDFs you choose are read in the extension on your device, merged or compressed there, and downloaded to your computer. The files are not uploaded. The extension does not request host permissions, does not run remote code, and does not include analytics.

The company site is https://free-utils.com.
